FINAL: Based on the indexed papers, chain-of-thought (CoT) reasoning is a technique designed to improve the performance of large language models on complex tasks that require multi-step logic, such as arithmetic, commonsense, and symbolic reasoning.

Key insights regarding CoT include:

*   **The Core Limitation:** Standard few-shot prompting often fails on complex problems because it only provides the final answer in examples. This prevents the model from learning how to decompose a problem into the necessary intermediate steps.
*   **The CoT Method:** Chain-of-thought prompting addresses this by including a series of intermediate reasoning steps within the few-shot exemplars. By showing the model the "worked path" to a solution, the model is better equipped to generate its own reasoning traces during inference.
*   **Evolution and Integration:** While CoT improves reasoning, it traditionally occurs entirely within the model, which can lead to hallucinations on knowledge-heavy tasks because the model cannot verify its reasoning against external facts. The **ReAct** framework builds upon this by interleaving these free-form reasoning traces with discrete actions (such as tool use or web searches). This allows the model to not only reason through a problem but also to gather external information and adjust its plan dynamically, effectively bridging the gap between internal reasoning and external action.
